# 초록·논문용 자료

학회 초록과 이후 전체 논문을 쓸 때 쓰는 자료를 모았습니다. 원고 자체는 저장소 밖에서 관리하고, 여기에는 다시 만들 수 있는 그림·숫자표·참고문헌만 둡니다.

## 파일

| 파일 | 내용 | 만드는 방법 |
|---|---|---|
| `key_numbers.md`, `key_numbers.json` | 초록·논문에 쓰는 핵심 수치와 각 수치의 출처 파일 | `python scripts/paper_numbers.py` (시뮬레이션 없음, 저장된 결과에서 다시 계산) |
| `references.bib` | 참고문헌. 쪽수·DOI를 확인하지 못한 항목은 `note`에 적어 둠 | 수동 관리 |
| `../../results/fig_kcs_abstract.png` | 1쪽 초록용 1행 3패널 그림 | `python scripts/fig_kcs_abstract.py` |

결과 파일이 바뀌면 `paper_numbers.py`와 그림 스크립트를 다시 돌리고, 원고의 숫자를 `key_numbers.md`와 대조합니다.

## 초록 그림 (`results/fig_kcs_abstract.png`)

초록 v3(2026-10-25)용입니다. 초록은 기준 논문의 에이전트 보정 워크플로에 식별가능성 점검 단계를 더하는 방향으로 씁니다. 이전 판(ND,eff profile, 실측 등가 7세트의 예측 Vth, 설계 규칙)은 커밋 645f871에 있습니다.

- (a) 도식. 기준 논문의 보정 루프(잔차 → 민감도 → 갱신)와 VD·L 전달 시험 뒤에, 더하는 단계(진단: Fisher·profile, 재정의: 조합으로 보고, 설계: 후보 시험의 σ_pred/잡음, 해소: t_ox·t_ch 분할과 C–V로 재보정)를 둡니다. 결과 파일을 읽지 않습니다.
- (b) 설계 단계(E19, 쌍둥이, 선형, 곡선 RMS). 시험 32개의 예측 σ ÷ 시험 잡음입니다. 드레인 바이어스(VD 0.02–3 V)·채널 길이(L 0.5–10 µm) 시험은 0.25–0.86으로 1 미만이고, 게이트 절연막(5–20 nm)·채널(2–10 nm) 두께 시험은 40.6–487입니다(최솟값 40.599).
- (c) 해소 단계(E22, 공개 데모, 해석 모델, 합성 데이터). 데모 컨트롤러 15회(trust radius 0.3–0.7 × 시작 φ_G 3개)의 끝점입니다. x는 데모의 보류(전이성) VD·L 시험의 최대 |ΔVth|, y는 t_ox 20 nm 소자의 Vth 오차입니다. 그림 축 이름은 기준 논문 용어에 맞춰 transfer-test로 썼고, (b) 제목에는 합성 데이터(synthetic)임을 밝혔습니다. 데모 보정 데이터만 쓰면 Q_f 5.7–10.0×10¹²(10은 Q_f 상한), t_ox 20 nm 오차 −499 ~ +5 mV입니다. t_ox 14 nm 곡선 1개를 더하면 Q_f 5.62–5.67×10¹², 오차 +11.2 ~ +14.3 mV입니다. 끝점이 같은 실행은 점이 겹칩니다.

## 서술 원칙

README 6.4와 5장을 따릅니다.

- "최초(first)", "exact gradient", "LLM 에이전트보다 우수" 같은 표현은 쓰지 않습니다.
- 기준 논문이 틀렸다는 서술 대신, 그 워크플로에 식별가능성 점검 단계를 더하면 descriptor 해석이 더 믿을 만해진다는 방향으로 씁니다.
- 비유일성 자체, 두께 분할·C–V를 이용한 분리, donor/acceptor 항등은 알려진 것으로 인용합니다. 기여는 전달 시험 통과가 파라미터를 정하는지에 대한 정량 평가, 수평/수직 시험 설계 규칙, 그리고 이를 묶은 점검 단계입니다.
- 상한은 올림으로 씁니다(예: Δχ²_eff 최대 1.264 → "≤ 1.27"). `key_numbers.md`도 같은 규칙입니다.
- 범위(같은 descriptor 클래스, 이 오픈소스 구현, 디지타이즈 데이터)를 밝힙니다. 실측 결론은 모델 오차를 포함한 σ_eff 기준의 상대 비교입니다.
- E20의 1σ는 선형화한 점에 크게 좌우되는 국소값입니다. 절대값보다 측정을 더했을 때 줄어드는 폭으로 씁니다.
- 133/376 mV는 v2·v3 차이가 포함된 값입니다. ND,eff 양 끝 차이(47/126 mV)와 구분합니다.
