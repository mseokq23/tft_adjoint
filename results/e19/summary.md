# E19: which kinds of test can tell calibration-equivalent parameter sets apart?

Linear check at the twin truth (Step 5). Calibration data: L = 1 µm, VD = 0.05/1 V. Noise σ = 0.02 dec on log10 ID for the calibration and for every test; Qf fixed (exactly degenerate with the gate WF for one gate stack). σ_pred/σ = predictive 1σ of the test given the calibration data, in units of the test's noise (RMS and max over the test curve). Below 1, the calibration-equivalent sets predict the same test result within its noise. sd ratio = 1σ of a descriptor after adding the test / 1σ from calibration only (1 = the test adds nothing about it). λ_max = the largest χ² the whole test curve can add per unit of calibration Δχ² (a set on the calibration's Δχ² = c boundary adds at most c·λ_max; below 1 the test cannot reject any set the calibration accepts). q = the same along the linearised ND,eff profile (other descriptors re-fitted); the two calibration curves sum to 1.

"max in window" = the largest single-point value at VG ≥ -0.60 V, where the calibration curves have points above the 10 pA floor (a test whose current is larger reaches further into subthreshold).

## Verdict

- Lateral/bias tests (calibration curves excluded): σ_pred/σ RMS at most 0.858 (L0.5_VD0.05); the largest single-point value is 3.57 (L0.5_VD1, VG = -0.65 V); inside the calibration window (VG ≥ -0.60 V) it is 1.28 (L0.5_VD0.05).
- Vertical tests: σ_pred/σ RMS at least 40.6 (tox5_VD0.05).
- Whole-curve factors: lateral/bias λ_max 0.836–42.5, q 0.373–14.3; vertical λ_max 1.02e+05–1.85e+07, q 2.91e+04–5.42e+06.
- Smallest sd ratio reached by any single lateral/bias test: log10_nd_eff 0.55, log10_n_ta 0.41, log10_n_gd 0.40, wf_gate 0.44, wf_sd 0.27, log10_mu0 0.24.
- Smallest sd ratio reached by any single vertical test: log10_nd_eff 0.26, log10_n_ta 0.10, log10_n_gd 0.16, wf_gate 0.00, wf_sd 0.13, log10_mu0 0.23.
